# ✈️ Split-Flap Display Generator

A zero-dependency, browser-based generator for creating authentic mechanical "split-flap" (Solari) display boards. 

With this tool, you can build a customized, animated schedule board—complete with procedural mechanical sound effects—and export it as a single, fully self-contained HTML file. Perfect for digital signage, OBS overlays, or just a cool retro dashboard.

## ✨ Features

* 🛠️ **Visual Web Editor:** A clean, Tailwind-powered UI to add, edit, and arrange rows on your board.
* 🔊 **Procedural Audio:** Authentic mechanical ticking sounds generated dynamically via the Web Audio API (no external `.mp3` or `.wav` files required).
* 🎬 **Organic Animation:** Randomized spin cycles and sequential character flipping that mimics the physical constraints of real Solari boards.
* 📦 **Single-File Export:** Generates a completely self-contained `.html` file. No assets folder, no build steps, no external dependencies.
* ⚙️ **Customizable Header:** Easily change the title of the board for different schools, businesses, or events directly from the UI.
